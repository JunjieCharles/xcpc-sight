# 网络赛高校综合排名视频卡片

2026 年三场网络赛按 ICPC 第一场、ICPC 第二场、CCPC 的固定顺序展示。输入使用经过 SHA-256 核验的官方 SRK；2026-09-23 核验三场线上版本与本地修订榜单一致，来源见生成脚本的 `INPUTS`。不使用个人 Rating 或前瞻预测排名。

## 排名规则

`scripts.school_ranking.school_standings` 是不访问文件、网络或绘图的纯计算函数，接收 `Contest` 元组及注入学校别名的 `DefaultNormalizer`，返回不可变学校/队伍结果。每场先排除打星、无提交队伍，按题数降序、罚时升序重建队伍总排名；0 题但有提交的队伍仍有效。按规范化学校合并，同校取最佳队伍成绩，再在学校间计算 `1, 2, 2, 4` 式校排。

综合比较各校三个校排名次升序组成的元组：先比最佳、再比次佳、最后比第三；缺赛视为正无穷。三个值都相等则并列，按规范化校名确定展示顺序，不增加未授权的第四项成绩规则。TOP50 包含综合名次不超过 50 的全部学校，如边界并列可能超过 50 张。

卡片中的三场校排始终保持比赛顺序，不改为排序后的比较元组。按用户指定，队伍详情选取任一场**队伍总排名前 100** 的所有阵容；若该校没有符合条件的队伍，则取三场校内最佳阵容的并集。候选队伍也按三场总排名的最佳、次佳、第三排序，卡片空间最多容纳前七队，完整候选保留在 JSON 中。跨场仅关联同校且全部规范化成员集合一致的队伍，不因队名相同或部分队员重合而合并；空成员使用场次内身份。改队名时展示最后一次有效参赛队名，同场重复阵容取最好成绩。正式结果中已移除的队伍没有该场成绩，不恢复被撤销记录。同校同名选手仍无法区分。

## 图片与复现

使用 Pillow 按参考 `2025/rating/generate_cards.py` 的结构绘制校徽、名次色带、校名色带和成绩明细。50 份原始校徽从用户已有的 `2025/rating/logos` 复制到受 Git 跟踪的 `assets/school-logos/`，附来源及 SHA-256 清单，生成脚本默认使用仓库素材，`--logos` 可覆盖。不同校区图案可能相同，沿用原素材，不生成或重绘校徽；缺徽报错。字体路径通过参数指定。

按用户最终排版要求，卡片不显示场次说明行。队名左对齐、三场队伍名次分为三个固定列，每列独立右对齐，共用同一文字基线；三列右边界分别为 394、482、570px，斜杠固定在列间，缺赛符号同样右对齐，各张卡片列位置一致。队名过长时缩小字体，不换行、不截断。每行高 42px，成绩区域整体垂直居中，最多七行；名次字号固定 28px。每张 600×1040 RGBA PNG，圆角区域透明，主体为白色。

输出位于 `video-scripts/2026-2027/2026网络赛高校综合排名TOP50/`：独立卡片、预览联系表、完整学校排名 CSV/JSON、来源和制作说明。该目录沿用仓库既有忽略规则，素材实际写入本地。生成脚本与纯排名模块受 Git 管理。默认测试不读取用户 OneDrive，不联网。

依赖 Pillow（`pip install Pillow`），在仓库根目录运行：

```powershell
.venv/Scripts/python.exe -m scripts.generate_school_cards --font "C:\Users\cjj\AppData\Local\Microsoft\Windows\Fonts\MiSans-Regular.ttf" --bold-font "C:\Users\cjj\AppData\Local\Microsoft\Windows\Fonts\MiSans-Demibold.ttf"
```

默认不联网；输入 SRK 放在 `INPUTS` 指定的缓存目录，缺失时按 `https://cdn.algoux.cn/rankland/file/{file_id}/{contest_id}.srk.json` 保存。每次运行先核验哈希和校徽是否齐全。字体和校徽可以通过参数换到其他位置；输出不依赖 Windows 字体默认搜索路径。

## 验证

`tests/test_school_ranking.py` 的六项离线测试覆盖同校最佳、学校别名、正式/无提交过滤、0 题失败提交、成绩并列、最佳/次佳/第三比较、缺赛、综合并列、跨场阵容匹配和改队名，以及前 100 的包含边界、校内最佳并集回退、空阵容和重复场次拒绝。

2026-09-23 生成 50 张独立卡片和 5 张联系表，完整榜单涵盖 552 所学校。独立按各校最佳题数/罚时统计严格更优学校数，核对全部三场校排；同时核验三份输入哈希、50 份校徽哈希、全部 PNG 尺寸及透明通道。六项测试和 Ruff 通过，目视检查首尾两页预览、七队密集卡片和长校名/队名，无文字碰撞。综合第 1、2、3、4、7、14 名学校的候选超过七队，图片展示前七队，JSON 保留完整候选。
